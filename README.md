# Śpiewak

A native Windows music player that respects your folders. WinUI 3 / .NET 10 + Rust, in one process. GPL-3.0.

Development requires Windows 11, Visual Studio C++ tools and Windows SDK, .NET 10 and Rust stable MSVC.

```powershell
.\tools\build.ps1                 # ARM64 (Parallels / Windows on ARM)
.\tools\build.ps1 x64
```

See [status](docs/STATUS.md) and the [implementation plan](docs/master-plan.md).
